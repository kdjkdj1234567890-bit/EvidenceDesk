# EvidenceDesk

소상공인이 자기 문서(지원사업 공고, 세무 안내, 임대계약 요약, 노무 기초)를 등록하고 한국어로 질문하면, **모든 답변 문장을 원문에서 그대로 인용하고 출처를 달아 주는** 근거 기반 답변 도구입니다.

Meta Global AI Developer Hackathon — Indie Developer Track, "Build for Your World".

## 왜 이렇게 만들었나

작은 로컬 모델은 한국어 문장을 창작하면 환각이 생깁니다. 소상공인에게 세무·자금 정보를 틀리게 안내하는 것은 치명적입니다. 그래서 EvidenceDesk는 **모델이 사용자에게 보이는 문장을 절대 쓰지 못하도록** 출력 권한을 제한했습니다.

- Meta Llama 3.2 1B Instruct (open weights, llamafile로 완전 로컬 실행) — 검색된 후보 중 **답을 담은 근거 passage를 선택**하고, 그 passage 안에서 **답변 문장 번호를 고르는** 일만 합니다 (모델의 문장 선택은 쿼리 n-gram 교집합 검증을 통과할 때만 채택, 아니면 결정론적 스코어러가 대체).
- 결정론적 코드 — 선택된 passage에서 **원문 문장을 그대로** 인용하고 `[n]` 출처를 붙입니다.
- 근거가 없으면 **답변을 거부**합니다. 모델 기술 오류 시에도 검색 신뢰도가 낮으면 거부합니다.

## 아키텍처

```
질문 → 한국어 bigram+trigram TF-IDF 검색 (순수 Python, 무공백 n-gram)
     → 상위 passage를 Meta Llama 3.2 1B가 선택 (번호만 출력, 생성 없음)
     → 코드가 원문 문장을 verbatim 인용 + [n] 출처
     → 근거 부족 / 모델 'none' / 저신뢰 → 명시적 답변 거부
```

- 외부 API 없음, 키 없음, 카드 없음, 완전 오프라인. 1 CPU / 2GB RAM에서 동작 확인.
- 서버: Python 표준 라이브러리만 (`http.server`).

## 평가 (eval.py, 24개 고정 질문: 답변 가능 18 + 답변 불가 6)

현재 코퍼스(v2, 전면 가상 문서) 결과: 답변 가능 18/18 정답 문서 인용, 정확한 거부 6/6. 이전 코퍼스(v1) 결과는 `eval-results-v1.json` 계열 파일에 별도 보존.

| 지표 | 검색만 | 검색+Llama |
|---|---|---|
| 답변 가능 18건: 올바른 문서 인용 | 18/18 | 18/18 |
| 답변 불가 6건: 정확한 거부 | 4/6 | 6/6 |
| 평균 응답 | - | ~1.9s (모델 로드+선택 포함) |

## 3-arm 절제(ablation) 평가 (eval2.py, 동일 고정 질문)

| arm | 구성 | 문서 정확도 | 문장 정확도 | 정확한 거부 |
|---|---|---|---|---|
| A | 결정론적 검색만 (Llama 없음) | 18/18 | 16/18 (0.889) | 4/6 |
| B | Llama passage 선택만 | 18/18 | 16/18 (0.889) | 4/6 |
| C | 전체 파이프라인 (passage+문장 선택) | 18/18 | **17/18 (0.944)** | **6/6** |

Llama의 관찰된 기여: 문서 수준에서는 검색과 동률, 문장 수준 근거 선택에서 16/18 → 17/18. **소규모 합성 평가 세트의 관찰값이며 일반적 성능 주장이 아닙니다.**
결과 원본: `eval2-armA.json`, `eval2-armB.json`, `eval2-armC.json`.

추가 안전장치: 질문 유형별 근거 검사(시기→달력 표지, 금액/수수료/세율→금액·비율 및 비용 명사, 세목명 코퍼스 존재 검사)를 통과한 문장만 인용합니다.

## 홀드아웃 반례 세트 (heldout.py, 8문항)

개발 완료 후 작성된 반례 8건(수수료/세율/비용 변형 + 통제 2건). 첫 실행 5/8 → 실패 3건 분석 후 위 규칙 3개 추가 → 8/8. **규칙 튜닝에 사용되었으므로 이후로는 미노출 홀드아웃이 아니라 회귀(regression) 세트입니다.** 일반화 성능 주장의 근거로 쓰지 않습니다.

정직한 한계 (숨기지 않고 기록):
- "문서가 용어를 언급하지만 답은 없는 경우"(예: 사업자등록증 **수수료**)를 인용해 버리는 실패 1건.
- 낮은 신호의 타 문서 유입("법인세율" → 세무 문서) 1건.
- Llama에 더 엄격한 yes/no 답변 가능성 게이트를 실험했으나 1B 모델이 과도하게 거부(답변 가능 5건 중 0건 통과)하여 **폐기**했습니다. 평가를 통과한 파이프라인을 출하합니다.

## 실행 방법

```bash
# 1) 모델 받기 (Meta Llama 3.2 1B, llamafile 단일 파일, ~1.1GB)
curl -L -o llama3.2-1b.llamafile \
  https://huggingface.co/mozilla-ai/Llama-3.2-1B-Instruct-llamafile/resolve/main/Llama-3.2-1B-Instruct-Q4_K_M.llamafile
chmod +x llama3.2-1b.llamafile
# 2) 실행
python3 app.py        # http://127.0.0.1:8090
# 3) 테스트·평가
python3 tests.py && python3 eval.py && python3 eval2.py A B C
```
